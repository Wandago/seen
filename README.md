# Wanlly Seen

A free directory at **seen.wanlly.africa** where Kenyan freelancers and small businesses get a personal portfolio site, built from a template and links to their work, and people reach them directly. No fees, no commission, no hosting of files.

- **Plan:** [`docs/PLAN.md`](docs/PLAN.md)
- **Clickable prototype:** [`prototype/index.html`](prototype/index.html) (open it in a browser; it starts with a guided walkthrough)

The app itself isn't built yet. The plan's Phase 0 starts it from the same setup as `wandago/wanlly-sign`.
